# Сила

Личное приложение для тренировок: программа, прогрессия, таймер отдыха, питание.

- **Приложение:** https://ivanovfilipp-maker.github.io/sila/ — открыть в Safari → «Поделиться» → «На экран „Домой“».
- `docs/` — само приложение (GitHub Pages).
- `server/` — сервер на Cloudflare Workers: сигнал конца отдыха на заблокированный экран и автоматические копии данных за 30 дней. Разворачивается автоматически (`.github/workflows/server.yml`), когда в Settings → Secrets → Actions есть `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`.

История тренировок хранится только на телефоне и на твоём сервере, не в этом репозитории.
